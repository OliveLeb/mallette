# Separate instance administration from content access

Instance administrators can configure the instance and manage accounts and invitations, but their role grants no implicit access to another account's personal files or credentials. They cannot replace another account's email or password and can access content only through the same ownership or shared-space membership rules as any other account. A server-side break-glass command may create a new verified administrator to recover administration, but never alters or impersonates an existing account. This is an application authorization boundary, not a zero-knowledge guarantee against the server operator who controls storage, PostgreSQL, and application secrets. It preserves personal-space privacy between application accounts at the cost of preventing administrator-assisted credential recovery, content recovery, and inspection.
